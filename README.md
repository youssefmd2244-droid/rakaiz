# موقع ركائز – دليل الرفع على GitHub والنشر على Vercel

## 1) قاعدة البيانات (مجانية)
1. اعمل حساب على https://neon.tech وأنشئ Project جديد (أو أضف تكامل Neon مباشرة من Vercel → Storage → Create Database).
2. انسخ رابط الاتصال (Connection string) – شكله:
   `postgresql://user:password@ep-xxxx.neon.tech/neondb?sslmode=require`
3. **مش محتاج تنشئ جداول** – الموقع بيعملها ويضيف البيانات الأولية تلقائياً أول زيارة.

## 2) رفع المشروع على GitHub
1. اعمل مستودع (Repository) جديد فاضي على GitHub.
2. من جهازك:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<اسمك>/<اسم-المستودع>.git
   git push -u origin main
   ```

## 3) الربط بـ Vercel
1. ادخل https://vercel.com وسجل دخول (يفضل بحساب GitHub نفسه).
2. **Add New → Project → Import Git Repository** واختر المستودع.
3. Vercel بيكتشف Next.js تلقائياً (الإعدادات جاهزة في `vercel.json`)، تقدر تسيب كل حاجة زي ما هي.

### متغيرات البيئة (Project → Settings → Environment Variables)
| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط قاعدة البيانات من Neon (أو أي Postgres). لو ضفت تكامل Neon من Vercel نفسه هيتحط تلقائي باسم `POSTGRES_URL` والموقع بيقرأه برضه. |
| `SESSION_SECRET` | ✅ (موصى به) | أي نص عشوائي طويل لتأمين تسجيل دخول الإدارة (`openssl rand -hex 32`) |
| `ADMIN_INITIAL_PASSWORD` | اختياري | كلمة سر الأدمن الأولى (الافتراضي 2004) |
| `NEXT_PUBLIC_SITE_URL` | اختياري | رابط الموقع النهائي |

بعد إضافة المتغيرات اعمل **Deploy** (أو Redeploy لو الموقع كان منشور قبل كده).

### بعد أول نشر (مهم)
1. افتح `https://موقعك.vercel.app/api/health` ← لازم تشوف `{"ok":true}`.
2. افتح `https://موقعك.vercel.app/api/seed` مرة واحدة ← بينشئ الجداول ويدخل البيانات الأولية.
3. بعدها افتح الموقع عادي.

### لو حصلت مشكلة
| المشكلة | الحل |
|---|---|
| `/api/health` بيرجع `ok:false` | راجع `DATABASE_URL` (انسخه كامل من Neon، ولو موجود `-pooler` في الرابط جرّب الرابط العادي) |
| الموقع بيفتح لكن الأقسام فاضية | نفس السبب فوق، أو افتح `/api/seed` |
| فشل الـ Build | Vercel → Deployments → افتح آخر Deployment → Build Logs |
| ماقدرش أدخل لوحة التحكم | تأكد إن `SESSION_SECRET` مضاف، وجرّب كلمة السر `2004` (أو `ADMIN_INITIAL_PASSWORD`) |

## 4) لوحة التحكم
- افتح `/control-panel` (أو اضغط 3 مرات سريعة على الشعار).
- المستخدم: `admin` – كلمة السر الأولى `2004` (أو اللي حطيتها في `ADMIN_INITIAL_PASSWORD`).
- **غيّر كلمة السر فوراً بعد أول دخول.**

## 5) الإعدادات ← إدارة كل صور وفيديوهات وأقسام الموقع
من لوحة التحكم ← الإعدادات، عندك دلوقتي 3 أدوات في مكان واحد:

### أ) صور وفيديو ونصوص الواجهة الرئيسية والأقسام الثابتة
استبدال فيديو الهيرو (نسخة كمبيوتر + موبايل)، صورة قسم «من نحن»، صورة قسم التواصل، والعناوين/الكلام المكتوب عليها.
اترك أي حقل فاضي عشان يفضل التصميم الافتراضي.

### ب) إدارة محتوى الصور والفيديوهات والأقسام (الأداة الرئيسية)
من هنا تقدر:
- **إضافة قسم جديد** في أي مكان في الموقع (بعد الهيرو، بعد "من نحن"، بعد الخدمات، بعد الإنجازات، بعد المشاريع،
  بعد الشركاء، بعد الشهادات، بعد العقود، بعد التواصل، داخل "من نحن"، أو أسفل الموقع).
- **إضافة صورة أو فيديو** لأي قسم — رفع من جهازك (بيتصغّر تلقائياً، حد أقصى 4 ميجا) أو لصق رابط (يوتيوب / Vimeo /
  رابط مباشر للفيديوهات الكبيرة).
- **إضافة كلام بدون صورة أو فيديو** (بطاقة نصية فقط).
- **تعديل / إيقاف / حذف نهائي** لأي قسم أو عنصر بداخله.
- **ترتيب** الأقسام والعناصر (لأعلى / لأسفل).
- **نقل أو تكرار** أي صورة أو فيديو من قسم لقسم تاني — حتى لو القسمين في أماكن مختلفة في الموقع.
- استرجاع الأقسام الافتراضية في أي وقت (قبل الحفظ فقط).

### ج) مكتبة الملفات
كل صورة أو فيديو اترفع من جهازك يظهر هنا مع حجمه، وتقدر تنسخ رابطه أو تحذفه نهائياً من هنا (حتى لو مش مستخدم في أي قسم دلوقتي).

### د) قنوات التواصل – شركة Icon Code
إضافة / تعديل / إيقاف / حذف أي أيقونة تواصل (واتساب، هاتف، إلخ) في أسفل الموقع، وإضافة أكتر من رابط للأيقونة الواحدة.

## نظام الألوان
- **الأساسي:** أبيض (الافتراضي) · أسود · دهبي – زرار القمر/الشمس في الهيدر بيبدّل بين الأبيض والأسود.
- **التزيين:** دهبي · أحمر · أبيض · أزرق · أخضر · بني · برتقالي (عن طريق `data-accent` – راجع `src/lib/accents.ts` و `src/app/globals.css`).
